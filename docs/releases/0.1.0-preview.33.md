# NetworkDiagramStudio 0.1.0-preview.33

## Organize connections

- A new Organize connections tool is always available in Edit drawing on network and wireless pages with cables.
- Analyze a bounded set of compact arrangements and compare connection length, bend count, crossings and drawing footprint before applying a change.
- Switch between Current and Proposed previews. Keep manual cable bends by default, or allow them to be rerouted. Cancel analysis without changing the drawing.
- Apply the accepted layout as one Undo step. Device sizes, port attachments, styling and other pages are preserved. Candidates with equipment, text or painted cable collisions are rejected.

## Compact, readable documentation

- Concise documentation shares identical network definitions across explicitly named devices and avoids repeating physical port membership in automatic trunk matrices.
- Complete physical assignments stay in Port Inventory. Unique VLAN, address, logical-interface, route and bridge information remains available.
- Automatic port-map layout combines small faceplates and inventory tables where it saves pages at a readable scale. Separate and Combined choices remain available, and existing edit identities are preserved.
- Full reference mode and custom trunk reports retain detailed membership matrices.

## Better spacing and wireless layouts

- Automatic core placement considers compact rows and columns while preserving saved reading order. Device and cable clearances are measured before placement.
- Place beside defaults to Automatic spacing based on labels and cable width. Compact, Standard and Extra room remain available.
- Stack gaps are smaller by default. Only gaps carrying crowded cables grow; physical chassis proportions and port anchors remain consistent.
- Dynamic wireless pages keep complete stacks and their APs together using measured caption banks. Fixed paper continues when the full readable layout cannot fit.
- Cable captions use available space without unnecessary narrow wrapping.

## Easier cable selection

- Nearby cables highlight before selection. A consistent 12 screen-pixel allowance beyond the painted edge works at every zoom level.
- The nearest eligible cable is used for click, drag and double-click, including crossing hops. Device artwork, text and bend controls keep priority.
- Keyboard cable and bend selection retain focus. Hover work does not rebuild or reroute the diagram.
- Editor highlights and interaction targets are excluded from SVG, print, PDF and native Visio geometry.

Save your project before installing an update. Installation and restart remain a separate user decision.
