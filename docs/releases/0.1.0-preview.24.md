# Dynamic canvas and device controls

- New drawings default to Dynamic / Fit all. Every device assigned to a core page stays on that page at its normal scale as the canvas grows.
- Fit bounds include labels, connection geometry and manual objects outside the original page, including negative positions.
- Print paper is independent of the canvas. Match the drawing for a full-size PDF, or fit each page onto a selected paper size. SVG and native Visio retain the drawing dimensions.
- Delete devices directly from the inventory. Clear all includes filtered and excluded devices and has an explicit confirmation. Undo restores devices, connections and page assignments.
- Search shows counts and device type/model/IP. Removed imported devices remain removed when reopening a project.

For an existing project with a saved paper size, choose **Page options > Canvas size > Dynamic / Fit all** to use the expanding canvas. New projects use it automatically.
