# NetworkDiagramStudio preview.47

## See settings changes before applying them

Global text styles, Pages & layout, and Page options now show a large read-only diagram preview beside the controls. Resize the controls area, select a preview page, zoom and drag to pan. Your inspection view stays set as you change options.

Changes are previewed from an isolated draft. Apply saves once and remains undoable. Cancel, Close or Escape leaves the original project and drawing unchanged. Invalid settings keep the last valid preview and display an error. Pause live preview or choose Update preview manually for more deliberate editing. If an automatic rebuild takes more than 750 milliseconds, the finished result remains visible and automatic rebuilding pauses to avoid repeating the delay; Update preview and explicit re-enable remain available. The first synchronous rebuild may still briefly block the controls.

This preview is not calibrated Actual size. Use the main canvas calibration/Actual size controls for physical paper checks. Page options previews visible-page geometry, not the separate print-paper projection. Large layout recalculations can take time. The new preview covers these three settings dialogs, not every application menu.

## Keep automatic diagrams on the selected paper

Automatic Letter/A4 fitting now keeps the complete core or wireless diagram inside the sheet instead of enlarging it beyond the page to meet the text target. If the target cannot fit, the app reports the actual smaller text size so you can choose larger paper or continuation sheets. Headers and docked keys retain their independent paper sizing. Deliberate manual off-page transforms and saved frames are preserved.

Fresh adaptive port maps use smaller edge gutters and no artificial locked-page socket-size ceiling. Hardware and its key fill more of the selected sheet without a second margin fit. Existing saved frames are retained to avoid moving authored content: use Page options, choose Letter/Auto-fit, and Save page options to deliberately recalculate a previously oversized or heavily padded sheet.

## Use empty space below the information panel

Moving a device or group now checks the panel’s actual occupied area rather than reserving an invisible full-height sidebar. Valid placement below a short key no longer snaps back; drag previews and committed positions agree. Real panel contents, cable routing and label collision checks remain protected, with Undo/redo and save/reopen preserved.
