# Easier diagram editing and cleaner physical connections

- Shift-click to select multiple items. Shift-drag any item to hold the initial horizontal or vertical direction. Modified clicks no longer open the double-click editor.
- Select devices and choose **Place beside...** to position them left, right, above or below another device, with space for captions and connections.
- Use **Size - / Size +** for quick resizing. **Size...** changes selected items, everything on one page or everything on all pages. **Align & space** groups the alignment tools.
- Use **Move to page...** to move selected devices to an existing or new named page, with off-page device and port indicators. Changes support Undo and saved projects.
- Cables have a wider selection area without thicker printed lines. Physical routes reserve clearer parallel spacing. VLAN, aggregate and subinterface observations stay in data tables and connection review instead of duplicating physical cables or creating false physical-peer conflicts.
- Large MAC-address lists now appear as a compact count on the drawing. Expand the addresses in Device details or enable **Device addresses (full list)** in the information panel to see every value.

Save your project, then choose **Download update > Install and restart**. Reopen the saved project or import the files again after updating. Device artwork remains shared with Configuration Inspector.
