# NetworkDiagramStudio 0.1.0-preview.13

- Hold Shift while dragging a cable or bend to lock horizontal or vertical movement. Releasing Shift restores free movement. Grid and alignment snapping respect the lock, and port endpoints stay attached.
- Edit cable type and speed from a legend swatch or Link styles, using presets or custom values. Apply changes to associated connection records, captions and legend summaries together. Mixed values remain unchanged until selected. Existing destination-type connections keep their own speed. Undo/redo and saved projects retain the edits.
- Add eight documented UniFi switch layouts, Netgate 2100/4200 and PA-455. Correct PA-415 management and ethernet1/1 combo sockets. The catalog now has 314 verified layouts covering 423 identifiers. Unknown models retain editable drawings appropriate to their inventory role, with boundary links until physical ports are mapped.
- Pack trunk VLAN matrices using measured headings and rows instead of a fixed six-column limit. Keep complete text, readable fonts and non-overlapping cells, and continue only when the data needs more room.
- Update the README, manufacturer references and fictional screenshots.
