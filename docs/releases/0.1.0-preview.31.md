# Visible placement tools and modular chassis routing

- Place beside stays visible in Edit drawing, with Left, Right, Above and Below controls plus spacing choices. Choose a side before selecting a device, or place an existing selection beside a reference device, without opening a dialog.
- Placement uses predictable gaps between device bodies. Nearby obstacle checks can make a small adjustment; when there is no nearby space, the drawing stays unchanged instead of moving devices far away.
- Reference devices and other equipment stay fixed during placement. Selected groups keep their relative positions, and zoom, undo, redo and saved project geometry are preserved.
- Modular chassis connections use clear channels beside the target module and the open center of the chassis. Leads avoid neighboring modules and management bays while retaining their correct port attachments. Exposed edge ports can use a short direct route.
