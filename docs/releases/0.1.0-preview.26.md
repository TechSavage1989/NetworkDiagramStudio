# Flexible pages, consistent ports and a growing canvas

## Pages and layout

- Open **Pages & layout**, or double-click a tab, to rename a page. Names appear in the drawing, SVG, printing and Visio.
- Create network, port-map, wireless, VLAN/routing and trunk pages from selected devices. A device can appear on multiple named network pages. Hide unwanted automatic pages while keeping continuous page numbering.
- Set drawing and text scales for all pages or override one page. Set a shared device scale, an individual device scale, or use **Edit drawing > Edit selected > Scale this object** for one object. Connections continue to use their port anchors.
- Report information panels show the devices on their particular sheet, including unmapped access-point tables.
- Set the information panel's width, scale, text scale and position. Choose connection types, port modules/GBICs, VLANs, addresses, models, routes, port details and custom notes.

## Hardware and canvas fixes

- Built-in socket artwork now uses common connector proportions on chassis modules, standalone switches and stacked members. Numbering, aliases and mapped centers are retained. Corrected three-row QSFP banks that previously shared two row positions.
- Dynamic pages can reserve additional space for crowded device titles instead of reporting that a device must move to another core page. Long module descriptions also grow the dynamic page.
- Saved manual positions, layout Undo/Redo, sidebar dragging, Up/Down, Delete, Clear all and separate print-paper choices remain available.

## Updating

Save your project before **Download update > Install and restart**. Existing saved page sizes and artwork overrides are retained. Built-in artwork remains schematic; imported picture/native stencils retain their supplied geometry and mapped ports. Only configure module models supported by the actual hardware.
