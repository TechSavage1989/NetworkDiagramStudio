# NetworkDiagramStudio 0.1.0-preview.11

- Configure cable type and speed directly on a line or in the connection editor. Presets include Copper, Fiber, MMF/SMF, SR/LR/ER/ZR, passive/active DAC, AOC/AEC, coaxial and serial. Speed presets range from 10 Mbps to 800 Gbps, with additional fabric rates and custom values. Imported labels retain their spelling and units. Choices describe the connection; they do not establish port capacity or installed optics.
- Save connection metadata, appearance and history together. A class change uses the selected class's shared color/legend style. Same-endpoint changes preserve manually edited bends, names and widths. Generic devices can use an explicitly named custom interface at a boundary attachment. Materialized handoffs remain in scope after imported-project save/reopen.
- Add 21 inventory roles, including server, hypervisor host, virtual machine, HCI node, storage, phone, workstation, printer, camera, controller and UPS. Generic symbols are editable vector geometry and do not invent physical jacks. Device forms include model suggestions and a separate platform/technology field; explicit role choices remain authoritative.
- Recognize 43 common server, storage, HCI and virtualization families with official references. Examples include Dell PowerEdge, HPE ProLiant, Lenovo ThinkSystem, Cisco UCS, NetApp, Pure, Nimble/Alletra, Scale HyperCore, Nutanix, VMware ESXi, Hyper-V and Proxmox. Custom models and stencils remain available. NIC/HBA/controller positions require the actual installed inventory and a mapped stencil. See the server/storage reference guide for coverage and sources.
- Render complete diagram captions with shared measured wrapping in SVG and native Visio. Port-module descriptions receive enough height and can continue to a module sheet. Handoff, project, wireless, logical-table and trunk headers retain their complete values. Impossible manually sized boxes report a clear error instead of silently truncating text. Existing caption edit keys and full-value inline editing are retained.
- Avoid duplicate wording such as Port port1; show port1 while retaining the underlying interface identity.
- Fix the disappearing diagram after adding equipment. Wrapped titles use their actual boxes for collision checks. Crowded automatic core sheets split equipment-owner groups into continuation sheets, retaining handoffs, connections and earlier edits. Rejected device saves keep the accepted project and open form intact. Failed same-project rebuilds retain the last valid drawing and disable stale exports until corrected or undone.

Validation passes 126 Node tests, seven independent damaged-package tests, four full synthetic Visio packages, actual browser-downloaded SVG/Visio files and native test-host compilation. Browser checks cover presets/custom values, target-class styles, bends, peers, generated handoffs, evidence reload, complete caption editing, device recognition, explicit roles/platforms, automatic continuation, rejection rollback, retained drawings, undo/redo and project round trips. Compact connection dialogs fit at 1366 by 768 with all controls visible. The hosted Windows run must pass for the final source head, including real add-device and edit-recovery interactions, export/print, update timing, installation and rollback. Direct Microsoft Visio rendering remains unverified in this environment.

Repository screenshots and fixtures contain fictional data. Uploaded customer diagrams/configurations remain outside the repository. Existing update feed, cadence, settings paths and separate download/install decisions are unchanged.
