# NetworkDiagramStudio 0.1.0-preview.37

## Complete stack port maps

- Builder-style port maps keep every physical member of a large switch stack together on one dynamic drawing page.
- The stack's VLAN and LAG key appears once. Member ports, tagged/voice VLAN marks, LAG outlines, numbering and editable objects are retained.
- Existing Port Inventory pages remain independent.

## Printing without rearranging the drawing

- Page options now select the printed paper and orientation, rather than resizing or repaginating the editable canvas.
- Letter, Legal, A4, A3 and other print formats fit each complete logical drawing proportionally on one sheet. Printing on smaller paper may reduce text readability.
- Existing saved drawing layouts are preserved when print paper is changed.

## Better page navigation

- Page tabs scroll horizontally, including mouse-wheel and trackpad use.
- Clicking a top-level group such as Port maps opens a scrollable dropdown of that group's pages. The current page is highlighted and can be changed directly.

Save your project before installing this preview. The Windows portable executable retains its existing name, NetworkDiagramStudio.exe. The application updater requires approval and a controlled restart.
