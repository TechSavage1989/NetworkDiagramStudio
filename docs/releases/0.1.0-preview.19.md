# 0.1.0-preview.19

- Wireless AP captions now include manufacturer/model and available MAC addresses. Core devices such as phones, printers and servers share the same identity details. Text remains editable and wraps in full.
- Device and port forms offer readable MAC address fields. Supported device/interface reports and operational captures retain reported addresses without treating learned forwarding-table addresses as local hardware identity.
- Core layouts preserve a common device width and each faceplate's proportions. Larger chassis and stacks continue onto another page instead of shrinking independently. Explicit user sizing remains available.
- Equipment can move to existing rendered pages or dedicated pages. Named groups can continue with their assignments and cross-page connection preferences retained.
- Browser context menus are disabled in the desktop and browser editions.
- The stencil search now clearly identifies selected local vendor files, explains empty searches and offers a search across all selected folders. It does not search the internet.
- Updated sample, screenshots and documentation.

Validation includes 171 Node tests, seven Python package tests, independent Visio package checks and actual browser editing, undo/redo, save/reopen, export and page-placement checks. Hosted Windows validation runs before publication. Direct rendering in Microsoft Visio remains unverified.
