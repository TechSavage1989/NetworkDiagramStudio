# NetworkDiagramStudio 0.1.0 preview 1

- Import supported switch/firewall configurations and Auvik device, interface and route exports into a local site workspace.
- Review device scope, port assignments, physical links, media types and hardware artwork before generating the drawing set.
- Export editable Visio drawings, reusable hardware stencils, individual SVG pages and printable drawing sets.
- Distinguish an observed AP uplink from an unused switch port that matches the same AP configuration.
- Use the standalone web edition offline or the portable Windows x64 application with explicit update download and restart controls.

This is the first preview. A parser or model entry does not certify a device installation. Check inferred links and assign the correct front panel and port mapping before distributing a diagram.
