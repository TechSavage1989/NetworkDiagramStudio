# NetworkDiagramStudio 0.1.0-preview.42

## More usable diagrams and page navigation

- Footer text and page numbering now default off independently, leaving more room for content. Page options can enable either; explicit saved settings are retained.
- Page groups and their pages now appear in an expandable sidebar list instead of top-screen tabs. Keep keyboard navigation, rename/context actions, the page picker and drawing controls.
- Keep all port map sheets together before port inventory pages.
- Align disjoint opposite-direction wireless runs on shared levels when full routing and painted-clearance checks permit it, including stack-member gaps.
- Plan wireless Auto-fit layouts for the selected physical paper before fitting the scene. Dense stacks continue across readable sheets instead of shrinking all AP details onto one page. Individual paper overrides, first edits and save/reopen retain a deterministic layout. Dynamic and Preserve existing layout remain available.

## Direct editing and clearer cable text

- Use proportional corner resize handles on selected objects and a rotation handle on text. Shift snaps text rotation to 15 degrees; Escape cancels a gesture.
- Select individual and native-device text directly and edit content, font, color, alignment and angle from the compact toolbar. Existing validated history and saved edits remain in use. Physical hardware rotation is not offered because its socket/routing geometry is not rotatable.
- Center cable labels and port numbers by default while respecting explicit alignment edits.
- Prefer port-link captions centered on their own associated line. Retain manual placement, and keep unrelated cable strokes visible through white caption backing rather than masking them.

## Expanded Switchport report compatibility

- Incorporate upstream 1.18.6 workspace paper/title migration, physical row-pair exterior numbers, dense marker fitting, shared-scale metadata and centered native raster fitting.
- Preserve native normalized configuration authority during fresh imports while retaining topology, observations and later manual edits. Source category selection also filters retained native report and supplementary evidence, without losing physical socket geometry.
- Expand browser normalization for IOS allowed/tagged-native VLAN policy, configured speed, management/mirror information and SVI data, with explicit conflict notices.
- The browser parser remains a bounded fallback, not exhaustive parity with the native engine. See docs/SWITCHPORT_INTEGRATION.md for the remaining vendor-specific gaps. Native standalone reports still fit their reference scene proportionally; small paper can reduce printed type.

Save open projects before updating. The portable application remains NetworkDiagramStudio.exe. Previous releases and assets are retained.
