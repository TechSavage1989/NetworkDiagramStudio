# NetworkDiagramStudio 0.1.0-preview.2

Devices can now be ordered with Up and Down buttons or drag and drop. Saved order applies to the core sheets and inventory views. **Device order / Core pages** assigns equipment to named core pages, excludes individual devices from the core, or includes connected access points in automatically fitted core pages. Overflow continues onto another sheet with page references for physical links.

The core renderer measures each faceplate and reserves cable clearance before packing a sheet. Links use orthogonal exterior lanes with a consistent pitch, independent departures from jacks, and arc jumps at perpendicular crossings. Optics remain confined to core sheets.

**Imported data** enables or disables individual imported configurations, Auvik XLSX/CSV files, and operational captures. Identity, ports, links, VLANs, routes and bridges can be selected separately. Supported show-command captures add interface state and speed, transceiver media, LLDP/CDP neighbors, VLAN names and observed routes. Local observations can be assigned to a chosen device. Manual changes survive changes to the included observations. Import categories and normalized records are retained in saved projects; raw configurations and command transcripts are not retained.

Visio import now preserves full master bounds and nested transforms for supported picture and vector masters. Artwork and named jacks use the same rotation and mirror transforms. Port mapping displays visible markers, existing mappings, and numeric coordinates. Device details provide a core faceplate scale. Legacy VSS and unsupported vector programs retain the desktop Visio conversion path.

Validation includes the Node suite, direct browser interaction, save/reopen, an actual rendered socket check on a synthetic rotated/mirrored vector-only master, six-master stencil reimport, and the private site project. Hosted Windows export, print, update and rollback validation is required before publication. Desktop Microsoft Visio validation remains outstanding.
