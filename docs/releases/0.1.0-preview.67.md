# NetworkDiagramStudio preview.67

## Editor

- **Page names fit the page picker.** A long page name, such as a wireless page named after its switch stack, stays on one line in the Page picker and other dropdowns. It ends with "…" before the arrow instead of wrapping into a cut-off second line. Hover the picker to see the whole name; the open list still shows every name in full.
