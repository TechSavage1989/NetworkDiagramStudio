# 0.1.0-preview.18

- Core pages can narrow the Connection Types and Port Modules sidebar before moving devices to another page. Captions remain complete and cable/legend thickness stays consistent.
- VLANs and routing are grouped by device. Sections share a page when they fit and repeat their headers when continued.
- Supported Visio stencil imports preserve embedded connection points, including unnamed sockets, duplicate names, nested transforms and zero-height wrappers. Invalid point coordinates produce a clear error.
- Legacy caption edits, manual sidebar geometry and saved port mappings are retained. Updated screenshots and contributor guidance reflect these changes.

Validation includes layout and import regression checks, source/offline browser editing and save/reopen, native Visio package validation and stencil export/reimport. Windows checks run before publication.
