# NetworkDiagramStudio preview.65

## Interactive HTML viewer

- **Smoother panning.** Dragging (or using the arrow keys) now moves the drawing as one finished picture instead of redrawing every shape on each step. On large network and wireless pages, the browser does 3 to 7 times less drawing work while you pan. The drawing redraws once, sharp, a moment after you stop.
- **Better zooming with a touchpad.** Zoom now follows how far you scroll: about 15% per mouse-wheel notch, and small, smooth steps for touchpad scrolling and pinching, instead of a 12% jump for every tiny touchpad movement.
- Each zoom step still redraws the page, so zooming a very large page is not instant.

## Editing

- Selecting a device and dragging it straight away is reliable on smaller windows. When a selection adds a row to the edit toolbar, the drawing is put back in place in the same step, so a quick press can no longer land beside the device.

Export the HTML again from this version to get the faster viewer: files exported earlier keep the old viewer.

Save your project before updating.
