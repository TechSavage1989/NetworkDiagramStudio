# NetworkDiagramStudio 0.1.0-preview.40

## More compact Port Inventory pages

- Reduced Port Inventory table text from 12 to 10 drawing units.
- Tightened row heights, text line spacing, column headers and inventory title bars.
- Used more of the printable page before continuing onto another inventory sheet.
- Maintained the original Port Map hardware scale, physical jack numbers, VLAN and LAG symbols, and all other drawing types.

All individual port assignments, descriptions, native and tagged VLANs, voice VLANs, LAGs, link states, connected-device details and editing keys remain intact. The Windows portable executable is still named NetworkDiagramStudio.exe. Save open projects before updating.
