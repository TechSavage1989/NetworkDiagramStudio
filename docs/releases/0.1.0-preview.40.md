# NetworkDiagramStudio 0.1.0-preview.40

## More compact Port Inventory pages

- Reduced Port Inventory table text from 12 to 10 drawing units.
- Tightened row heights, text line spacing, column headers and inventory title bars.
- Used more of the printable page before continuing onto another inventory sheet.
- Maintained the original Port Map hardware scale, physical jack numbers, VLAN and LAG symbols, and all other drawing types.


## Diagram editing and labels

- Added right-click editing menus for drawing objects and page tabs.
- Double-click a page tab to rename it and synchronize the visible page title.
- Connection-label alignment identifies physical endpoint devices and ports, with adjustable position along the link.
- Choose **Above line**, **On line (with a centered break)**, or **Below line**; vertical links use the equivalent left/on/right positions. Choose automatic cable direction or a fixed rotation. Saved placement follows later rerouting.
- Wireless connections departing toward opposite sides can share a centered level without crowding same-side lanes.

## Global text and selection tools

- The primary toolbar now includes **Text styles**, offering global size, color, weight and alignment presets for ten kinds of document text. Defaults apply to existing and newly generated labels while explicit object edits retain priority.
- Connection type legend lines and their matching cables highlight one another on hover and selection, including the legend description text. These temporary editor highlights are never included in exported files.
- Edit drawing offers **Spacing...** for already positioned selections, with a fixed horizontal/vertical edge gap or even distribution inside their current bounds. The first object in spatial order remains anchored for fixed spacing; Undo restores previous positions.

## Configurable page details

- Reorder, enable, disable and rename individual sidebar sections, including modules, connection types, VLANs, LAGs/LACP, AP links, VSF ports, uplinks, optics and custom text.
- Summarize port modules by type or show complete device-to-port assignments.
- Preserve full device address and MAC details, even with custom sidebar sections.

All individual port assignments, descriptions, native and tagged VLANs, voice VLANs, LAGs, link states, connected-device details and editing keys remain intact. The Windows portable executable is still named NetworkDiagramStudio.exe. Save open projects before updating.
