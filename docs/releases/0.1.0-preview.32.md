# Integrated switchport reports and shorter cable routes

- Integrates the Switchport Diagram Builder 1.18.5 report engine and verified hardware catalog into the existing project, device and export workflows. Open saved Switchport workspaces and supported unencrypted RouterOS backups.
- Adds wall charts, A4 one-page reports, complete inventory booklets, shared multi-device sheets and the eight-file technician package. Includes vector PDF, 300 dpi PNG, CSV, JSON, summaries and validation reports, plus independently selected supplementary evidence.
- Keeps shared VLAN and LAG colors, native/tagged/voice markers, stack/disabled indicators, optional logos, device/member/module names, serial numbers, asset tags and notes. Port numbers sit above or below the sockets at readable sizes.
- Groups drawing pages into a compact navigator and consolidates export choices. Place beside remains visible whenever Edit drawing is enabled.
- Reduces automatic routing work after movement, reuses unchanged page plans and removes distant page-wide cable detours. Clear short routes take priority, with nearby outside approaches, separate stroke-aware cable lanes and port-top clearance. Manual cable edits and glued endpoints remain intact.
- Recovers imported FortiGate-to-switch connections when a configured short hostname and its unambiguous FQDN describe the same device. Keeps alternate HA-interface observations for review without drawing duplicate data cables.
- Preserves successful files when another report cannot render, records export validation results and retains the last successful native package after a cancellation or failure.
