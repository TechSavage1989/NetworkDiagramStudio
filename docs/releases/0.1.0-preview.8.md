# NetworkDiagramStudio 0.1.0-preview.8

- Edit text colors with the full visual color picker: saturation/brightness spectrum, hue, system chooser, HEX/RGB/HSL values, drawing colors, recent colors and named saved swatches. This includes device titles, port labels, legends and supported native stencil text. The inline text editor has a quick color chooser and Text options opens the full picker. Text colors persist in saved projects, SVG and native Visio exports, with Undo/Redo support.
- Port maps default to compact tables with wider description fields and combined connection details. Continuation sheets use the full table area instead of repeating the faceplate. Port map options retain an expanded layout and optional repeated faceplates. Numeric ordering, consecutive matching groups and detail filters remain configurable. Long records wrap and continue without dropping text. The reference site's port-map section decreases from nine pages to three while retaining all 104 port records.
- Double-click editable elements for their properties, or double-click text to type directly on the drawing. Enter saves and Escape cancels. Saving or exporting commits a valid inline edit first. Device names stay near their devices and can be moved independently.
- Drag a selection rectangle in Edit drawing, Shift-add or Ctrl-toggle items, then drag, align, distribute or nudge the selected group. Arrow keys use the configured step, Shift multiplies it by ten and Ctrl divides it by ten. Space-drag and the middle mouse button pan; zoom and Fit page remain available.
- Configure grid snapping, spacing, alignment guides, target classes and movement steps per project. Snapping starts disabled, and Alt temporarily bypasses a snap during dragging. Keyboard nudges preserve their exact step.
- Ctrl+Z, Ctrl+Shift+Z, Undo, Redo and Undo all cover available project history, including drawing edits, colors, endpoint connections, port mappings, imports and settings. History retains up to 200 actions in the current session. Port mapping also provides scoped undo controls.
- Cable controls add, remove, drag and numerically edit bend points while retaining orthogonal geometry and attached ports. Connect endpoints selects the specific device and physical port at each end, checks occupied aliases and preserves link styling. Core routing prefers fewer bends and uses consistent exterior lanes when necessary.
- Link colors have a full visual picker plus opacity. Legends show only link types and color/opacity combinations used on their sheet. Crossings show arc hops with white clearance; Visio exports retain editable connectors with native jump settings. Core port numbers, media and speeds remain visible.
- Port mapping includes rectangle selection, group movement, horizontal/vertical alignment, equal spacing, modified arrow nudges, zoom, Fit device and panning. The stencil master picker supports model/name searches and retains selections while filtering. Recursive folder discovery includes all twelve Visio file extensions; artwork conversion support remains format-dependent.
- Recognized hardware uses sourced faceplate and port-bank profiles. Unknown layouts retain boundary attachments and manual mapping rather than invented socket locations. Imported endpoint evidence remains reviewable. No HA link is inferred merely from the existence of an HA interface.
- The editable flat network icon is applied to the Windows executable/window and browser header/favicon. Its SVG source is included in the repository and offline ZIP.
- Update checks show progress, installed/latest versions and a copyable diagnostic report. Publishing this preview through the existing public feed gives earlier installed previews a newer verified executable to offer. Checking, downloading and installing remain separate operations, with the same cadence and settings location.

Validation includes 65 Node tests, browser mouse/keyboard checks for text colors and the existing drawing/mapper tools, project round trips, export color checks and compact pagination coverage. The release workflow requires hosted Windows build, native export/print, real timer/focus checks, verified installation, rollback and settings/filename preservation before publication. Direct opening and rendering in desktop Microsoft Visio remain unverified.
