# NetworkDiagramStudio 0.1.0-preview.35

## Port maps in device colors

- Port maps now use the Switchport builder sheet by default, on US Letter (or the fixed port-map paper you choose).
- Each sheet takes the colors of the device's artwork in the network drawing: the switch plate color, or for a chassis the frame color around module-bay-colored slots. Port numbers and slot captions turn white on dark plates.
- The realistic faceplate style is still available under **Port map options > Port map style**. In that style, the chassis slot line now moves to the next sheet instead of overlapping the footer key.

## Larger, centered VLAN dots

- Jacks grow until the map and its VLAN key fill the sheet. The port-number size, never below 8 px, is chosen to give the largest dots.
- Each map uses one dot size for all its ports: the largest at which its busiest port still holds every tagged VLAN. Dots are drawn as a centered grid that grows outward from the middle of each jack.
- SFP+ cages on port maps are slightly taller while staying rectangular.
- Switchport Reports exports keep the builder's own dot layout.

## Verification and limitations

- The full browser/Node regression suite, Windows portable build and native smoke checks run on the merged release commit. Synthetic test data only is included in the source and release.
- Opening a generated file in a local desktop Microsoft Visio installation is not part of the automated test gate.

Save your project before installing a new preview. The application updater still requires normal installation approval and a controlled restart.
