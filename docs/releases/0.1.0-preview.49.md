# NetworkDiagramStudio preview.49

## Direct controls and clearer workspace

Drag the divider beside settings controls to resize them directly. In narrow windows, drag the divider up or down. Keyboard arrows, Shift+arrows and Home/End also work. Resizing keeps live preview, pan and calibrated scale independent.

Drawing commands are grouped by purpose, with Edit drawing directly accessible. The active page has paper-size and orientation controls without opening a dialog; the lock and fitting status are visible. Changes remain undoable and apply to that page only. Full Page options remain available for custom sizes and advanced settings.

## Readable wireless paper layout

In Page options, choose Wireless paper layout → Optimize APs for paper (readable). This explicit mode measures actual AP caption size, rearranges and enlarges AP cards around the complete stack, and continues onto additional sheets when needed to meet the text target. Every link remains represented. Existing proportional layout is unchanged; deliberate manual edits and frozen layouts remain protected.

Dense physical socket artwork may still be small. Full port labels on AP cards help identify connections; use port maps for detailed socket inspection. Longer captions can require more sheets than short captions.

## More consistent equipment and paper defaults

New projects start port-map pages on Letter landscape; existing saved page sizes and explicit choices stay unchanged. Schematic optical ports use a common size, preserving connector metadata and deliberate manual geometry. Aruba 6000/6100 twelve-port bank gaps and supported MikroTik faceplates now use model-specific grouping. Imported artwork is not rewritten.

The decorative vertical information-panel line is removed without changing its content or collision protection.

Save your project before updating.
