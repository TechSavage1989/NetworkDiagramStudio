# NetworkDiagramStudio preview.61

## Port maps

- **Edit any port map text.** Double-click a header, heading, note or key line to change its wording. The panel body still opens **Port map details**.
- **Unconfirmed modules are drawn as ports**, as in the Switchport builder, rather than as a text list. They show short port names (for example Gi49, Te1). The Catalyst 3560-E uplink also lists its X2 / TwinGig alternatives, without claiming which module is installed.
- **Headings no longer overlap** the rows below them.
- **Rounded corners** on panels, headers, ports, LAG/trunk outlines and key swatches, in SVG, PDF and Visio.
- **Tagged-VLAN dots** can now use the space over the port's latch line when a busy port needs it, so dots stay larger.
- **The page margin applies to all four edges**, including the dark header band and chassis frames.

## Port Inventory

- No color block in the lists.
- **Interface pages** are named after their devices and use the same smaller table text as the other Port Inventory pages.

## Devices and text sizes

- **Devices are listed in network order automatically**: firewalls and routers first, then switches from the edge inward, then access points and other devices after the switch they connect to. Stacks stay together. Once you move a device by hand, your order is kept. Use **Device order → Sort by network hierarchy** to apply it again.
- **Printed text size is now shown.** Font sizes in the editor are at full drawing size. A page fitted to its paper prints smaller, and the page warning reports that printed size. The Size box and Properties now show what the selected text prints at, for example "prints 3.8 pt".

Save your project before updating.
