# NetworkDiagramStudio 0.1.0-preview.43

## Device rotation and separate page navigation

- Rotate a selected device with its round handle or a precise angle field. Hold Shift for 15-degree steps, reset its rotation with one click, and undo the whole edit together.
- Physical sockets rotate with the artwork. Connections reroute to the same mapped ports, while SVG, print/PNG, vector PDF and editable Visio retain the rotation. Saved projects reopen with the same angle. Individual artwork text remains directly editable inside rotated devices.
- Rotations use conservative clearance checks. Move neighboring equipment apart if the requested angle would overlap another device, a caption or an unsafe cable departure. Flattened Switchport report pages do not contain device groups and do not expose device rotation controls.
- Drawing set pages have their own scrolling sidebar immediately beside the project/import/inventory sidebar. On narrow windows the navigation panels move above a full-width drawing area. Page groups, rename, keyboard navigation and scope menus remain available.

## Clearer editing, information and sharing

- Choose familiar port roles and link speeds from dropdowns while retaining custom values. Select native/tagged VLANs already present in the document, or enter IDs manually. Invalid input is brought into view without discarding edits.
- Port/link label backings follow the text rather than the selection box. Choose white or transparent and set padding from 0 to 20 drawing pixels; the default is a minimal 0.5 pixels. Unrelated lines remain visible above white backings.
- Information panels show unique document VLANs by default, with optional device grouping, address and port filters, row limits and explicit empty-data explanations. Layout validation appears next to Apply and preserves the form for correction.
- Export a portable, read-only interactive HTML drawing set with page navigation, search, zoom, pan and label inspection. It works offline and contains rendered drawings, not original project evidence.
- Choose Models to resize selected objects in place or Layout spacing to adjust their separation without resizing. Side-docked information panels follow the resulting diagram bounds.
- Group selected objects to move, scale or rotate them around one shared pivot without flattening artwork. Ungroup retains positions. Internal spacing/alignment changes require ungrouping first.
- Lock a selected physical page size. It fits once and then preserves the saved scale and position; edits that exceed the boundary are rejected instead of silently enlarging the paper or shrinking everything.
- Associate existing devices as a named stack with explicit member numbers. Membership appears in drawing/export captions. Removing a member or dissolving a stack preserves its devices, ports and links; visual grouping and hardware composition remain separate.


## Consistent report sockets and broader saved-configuration imports

- Use the same socket dimensions and aspect ratios across fixed, chassis and stacked port maps. Wider chassis panels no longer stretch their ports. SVG, PNG, PDF and native report geometry use the same rule.
- Expand Cisco, Comware and RouterOS saved-configuration handling, including effective interface policy, aggregate behavior, renamed physical interfaces and qualified routing records.
- Preserve multiple VLAN addresses and native configuration authority without retaining stale effective VLAN values or reapplying aggregate defaults.
- Browser imports remain a bounded fallback, not a claim of exhaustive vendor syntax parity. Unsupported recognized switching paths are blocked instead of generating misleading reports; qualified or unsupported routing references remain explicitly identified. See docs/SWITCHPORT_INTEGRATION.md for current limitations.

Save open projects before updating. Previous releases and assets remain available. Interactive rendering in the Microsoft Visio application has not been verified.
