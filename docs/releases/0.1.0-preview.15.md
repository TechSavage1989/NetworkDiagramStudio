# NetworkDiagramStudio 0.1.0-preview.15

- WAN, circuit and ISP cards use compact widths based on their full labels and fit within the main device body. Narrow devices use additional rows.
- Circuit routes use space inside the stack width when port orientation and clearances allow. A single facing-port connection can be straight; necessary exterior paths stay close to the body.
- Longer provider and gateway labels wrap without truncation. Cards spread within the available width when needed to keep cable labels separate.
- Existing manual device/card positions and sizes remain editable. The README screenshot shows the updated layout.

Validation covers compact and dense WAN layouts, complete captions, cable/label clearance, saved edits, browser and offline rendering, and the native Visio export package. The conditional update bar from preview.14 remains included.
