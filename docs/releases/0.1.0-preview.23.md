# NetworkDiagramStudio 0.1.0-preview.23

## A clearer update experience

- **Readable release notes:** Review section headings, highlights, bullet lists and complete descriptions in one clean panel inspired by Configuration Inspector.
- **Compact version comparison:** See the installed version and the available release together, without oversized version cards.

## Your work stays under your control

- **Visible progress:** Download and verification states explain what is happening. Close the review to keep working and reopen it to see current progress.
- **Actions within reach:** The footer stays visible when release notes are long or the app window is small. Cancel, Check updates and Install and restart remain easy to reach.
- **Clear restart guidance:** The install screen explains recovery and reminds you to save your project. Saved project files and preferences are retained; unsaved diagram changes are not automatically restored.
- **Familiar recovery:** The existing verified download, separate installation confirmation, busy checks, automatic check timing and previous-version backup remain unchanged.

Existing projects, hardware layouts and drawing edits are unchanged. The redesigned screen appears after installing this version; the update from an older version uses that version's existing screen.
