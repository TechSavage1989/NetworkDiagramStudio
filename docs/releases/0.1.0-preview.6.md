# NetworkDiagramStudio 0.1.0-preview.6

- Select a cable in Edit drawing to see its bend handles. Drag an existing bend, use a segment's plus control to add a detour, or select a bend and use Remove point/Delete. The numeric bend editor supports adding, moving and removing points. Port endpoints remain attached and the cable remains orthogonal. Arrow keys nudge a selected bend; Shift uses a larger step and Ctrl uses a fine step.
- Connect endpoints selects the exact device and physical port at either end of a link. Available choices include unused sockets from recognized models or mapped stencils. Occupied ports and known physical aliases are checked. Reconnecting reroutes the cable and preserves its color/style. A generated WAN handoff becomes an explicit project device/connection only when its endpoint edit is saved.
- The line color picker includes a saturation/brightness spectrum, hue slider, native system picker, HEX/RGB/HSL entry, opacity, network presets, colors used in the drawing, recent colors and named saved swatches. Screen sampling is available when supported by the browser. Color and opacity persist through project save/reopen, SVG and native Visio export.
- Core and wireless legends list only the link types and color/opacity combinations used on the current sheet, including custom cable colors. Media labels follow the cable's edited color while retaining a readable dark color for pale lines.
- Perpendicular cable crossings have larger arc hops with white clearance. Hops are recomputed after edits and included in core label/title collision placement. Visio exports retain editable orthogonal geometry with native arc-jump settings so Visio can recalculate jumps after editing.
- Port mapping supports rectangle selection, Shift-add/Ctrl-toggle, group dragging, wheel zoom, Fit device, and Space/middle-button panning. Arrow keys move selected ports by one screen pixel, Shift by ten and Ctrl by one tenth. Positions remain normalized to the faceplate. Group movement preserves spacing when clamped at an edge. Selection and zoom do not move ports. Place port is a separate mode.
- Port detail tables have clearer columns, numeric member/slot/port order, whole-row pagination and actual peer names/ports. Only consecutive identical records group together. Port map options can show all records, hide records without assignment details, or retain only ports with a peer/description. Row grouping and filters persist in the project. The faceplate retains all physical port records.
- A flat network-topology icon is applied to the browser header/favicon and the Windows executable/window. The editable SVG source is in src/web/assets/app-icon.svg. The Windows resource contains 16 through 256 pixel sizes.
- Update checks display progress for automatic and manual lookups, use a bounded 25-second lookup deadline, and report the installed and latest published versions. A locally supplied newer build explicitly reports that it is ahead of the published feed. Update details shows the feed, last HTTP result, timestamp and result with a copy control. The feed, automatic cadence, asset verification and separate download/install decisions are unchanged.

This candidate includes the unpublished preview.3 through preview.5 changes. Public release publication requires its own authorized scope and passing hosted Windows checks. The live feed verified during this work contained only preview.1 and preview.2, so it cannot deliver this candidate automatically yet.

Local checks cover 57 Node tests, browser mouse/keyboard interactions, policy/cache/rate-limit behavior, rendered synthetic screenshots and the reference core layout. Windows production/test-host compilation, cross-publishing, PE identity/icon resources and current embedded editor checks passed. Hosted native Windows export/print, real timers, previous-to-next installation/rollback, installed Visio conversion and opening the exported drawing directly in Visio remain required validation outside this Linux workspace.
