# NetworkDiagramStudio 0.1.0-preview.41

## Port maps that fit the selected page

- Replaced the forced two-column landscape layout with a measured page-fit search based on Switchport Diagram Builder's approach.
- A4, Letter and other visible page sizes compare ordered member layouts and legends beside or below the hardware, then use the largest readable shared socket size.
- Five-member and eight-member stacks can retain their original vertical member order rather than being spread horizontally and shrunk.
- Reserve space for headings, the complete VLAN/LAG key, port numbers and the footer before sizing the hardware. Avoid shrinking an already fitted page a second time.
- Apply individual page overrides as well as page-group and drawing defaults. Keep independent print paper and Preserve existing layout behavior.
- Preserve all physical interfaces, VLAN markers, LAG outlines, stable editing keys and saved object overrides. The first drawing edit keeps the accepted adaptive layout for the other objects.

This change applies to builder-style Port Map sheets in the main drawing set. Standalone Switchport Reports and their native export engine are unchanged. Extremely dense content that cannot meet readable limits retains the existing logical-canvas fallback.

Save open projects before updating. The portable application remains NetworkDiagramStudio.exe.
