# NetworkDiagramStudio preview.63

## Port maps

- **Tagged-VLAN dots fill each jack.** Each port's dots are as large as its own jack allows, instead of one small size for every port on the map. Crowded SFP ports use the full row height when that gives them noticeably larger dots.

## Pages

- **Every set of sheets is named after its devices.** Wireless pages, Port Inventory, VLANs and Routing, and any future multi-sheet pages are named after the devices they show. Port map sheets read "SWITCH-NAME / Port map".
- **New projects start on Letter landscape paper**, with **Edit drawing** and **snapping** turned on. Existing projects keep their saved settings.

## Text sizes

- **Sizes show what prints.** The Size box and object Properties show the size the selected text prints at on the open page (and accept sizes the same way), so they match the readability notice.
- **The notice takes you to the text.** When the page bar reports small text, click it (or **Show**) to select and reveal the smallest item; **‹** and **›** step through every item below the minimum.
- Notices stay on one line in the page bar, so the drawing no longer jumps after you drag something.
- **Device names and details are one size across a page.** Every device on the page uses the same size for its name and for its details.

## Wireless pages

- **Port numbers stay in line with their sockets.** A cable leaving through a row of numbers now passes behind its own number instead of pushing the whole row onto the edge of the faceplate.

## Connection types

- **Add your own connection types** with a name, color and width: Link styles → **New connection type…**.
- **Change only the connections you choose.** In Edit drawing, select one or more cables and click **Connection type…** to give just those cables another type, or a new one. Every other connection keeps its type, and the key lists the new type.
- Properties shows a cable's saved line width.

Save your project before updating.
