# NetworkDiagramStudio preview.70

## Drawing set

- **Firewall port numbers.** FortiGates and other firewalls (and routers) now show port numbers on their faceplates on the network page, as switches do. Their sockets are small, so the numbers can be smaller than on switches. A port with a cable keeps its cable label instead.
- **Cables over port numbers.** Where a wireless cable rises straight out of its port across the port's own number, the cable is now drawn on top of the number instead of being hidden behind it.
