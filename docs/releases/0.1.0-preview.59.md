# NetworkDiagramStudio preview.59

## Pages keep a 5 mm border, and the information panel always fits

- Every drawing page now keeps a **5 mm blank border on all four edges** by default. Change it in **Paper & print → Page margin (mm)**.
- When the information panel has more rows than fit down the sheet, it continues in **side-by-side columns** instead of running off the page. Text gets smaller only if the columns still don't fit, and never below 5 pt.
- Long notes now flow line by line into those columns. Editing any line still edits the whole note.

## Port maps

- Every port map ends with **"Confirm live link, LLDP/CDP, and MAC address table before moving production cables."**
- The key now has separate **VLANs** and **LAGs / trunks** headings. Long lists use slightly smaller text so the map keeps its size.
- Each device or stack member heading shows the **member number, model and hardware**, for example *Member 2 | JL256A | 48 RJ-45 + 4 SFP+*. It also shows the serial number and asset tag when they fit.
- **Port descriptions** are listed under the key when they all fit on the sheet.
- **Double-click a device on a port map** to edit its port map details:
  - device name, model (from the hardware list), management IP and MAC;
  - for the switch, stack member or module you clicked: display or module name, serial number, asset tag and notes.

  These are the same details the Switchport builder keeps. One Undo puts them back.
- A device with its own **imported stencil** now shows its port map on that artwork. To use the builder sheet for every device instead, change **Port map options → Devices with an imported stencil**.

## Port Inventory: fewer pages

- Tables print at 8 pt with tighter rows.
- The next device's table starts on the same sheet when it fits.
- Tables start at the top of the page.

Save your project before updating.
