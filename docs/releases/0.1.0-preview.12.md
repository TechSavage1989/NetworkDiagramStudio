# NetworkDiagramStudio 0.1.0-preview.12

- Add and edit device ports through labeled fields for name, description, role, speed, native VLAN and tagged VLANs. Add/remove rows without writing JSON. Unchanged imported properties remain intact. Connected port names and removal are protected until their connection is edited.
- Choose a device's core page directly in Device details: automatic placement, an existing page, a dedicated new page or exclusion from core pages. Selecting a current automatic page preserves its existing group as a named page. Device order / Core pages controls page names, off-page references and individual connection visibility.
- Fit more core equipment on a page by reserving handoff clearance and trying denser layouts before continuing. Capacity overflow moves the last owner group with its handoffs. Existing device edits validate before acceptance, preserving the last valid drawing on rejection.
- Place link captions beside a segment of their own cable, with matching horizontal or vertical orientation. Collision checks use the rotated footprint. Displaced captions use short leaders, and cross-page markers repeat link identifiers to keep close connections distinguishable.
- Increase the default cable and legend line weight to 4 drawing units / 3 pt. Preserve explicit manual line widths. Visio legend samples now use the same editable native one-dimensional line shapes as cables, with shared document styles and same-sheet stroke references. Editing a legend sample's line color, weight or pattern in Visio updates the linked cable stroke cells.
- Refresh the documentation and fictional screenshots for the current port and page controls.

Local verification covers the browser engine, four synthetic Visio packages, damaged-package rejection and the offline web build. Hosted Windows validation must build the final candidate and exercise native exports, printing, update checks, installation, rollback and settings preservation before publication. Package checks verify native line types, shared styles, cached stroke values and port glue. Direct rendering and interactive editing in Microsoft Visio remain unverified in this environment.
