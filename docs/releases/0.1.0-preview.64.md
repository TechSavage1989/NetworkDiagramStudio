# NetworkDiagramStudio preview.64

## Port maps

- **Full-size dots on busy ports.** The * (a trunk allowing all VLANs) and ! (disabled) marks now sit beside the port number instead of inside the jack, so the VLAN dots fill the whole jack. Ports like a busy SFP trunk or an uplink module's Te ports show much larger dots.
- The key explains the mark: "* All VLANs allowed (trunk policy)".
- **Compact rows.** The two rows of every port panel sit almost touching, with numbers above the top row and below the bottom row, saving vertical space.
- An unconfirmed uplink module has a one-line "Uplink interfaces" heading. The note about which ports are alternatives is one small line under the key.

## Connection types and the key

- **Show a type in the key before using it.** New connection types have a "Show in the connection key" option (on by default), so they appear in the network page's CONNECTION TYPES key straight away. Link styles turns it on or off for each of your types.
- **Add a connection from the key.** Double-click a key entry (or open Link styles) and choose **Add connection of this type…**: Add connection opens with that cable type chosen.
- To change the type of several connections at once, select their cables in Edit drawing (Shift-click) and use **Connection type…**.

## Pages and text

- **Locking a page no longer changes any text.** Names and details keep their size and place when you lock a page, and after reopening it.
- **Names and details stay closer to their device.** When cables or labels block a caption's usual corner, it now takes a spot right against the device on the other side or beside it instead of moving far away.
- **Short VLANs and Routing page names.** A page of shared records is named "Shared" instead of listing every device, and every entry in the Pages list is at most two lines (hover for the full name).
