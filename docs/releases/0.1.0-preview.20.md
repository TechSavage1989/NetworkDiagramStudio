# NetworkDiagramStudio 0.1.0-preview.20

- Choose Letter, Legal, Tabloid, A5 through A1, or custom paper in Page options, with portrait or landscape orientation. Set one default or separate paper sizes for core, port-map, wireless, VLAN/routing and trunk sheets.
- Reflow tables and diagram layouts for the chosen paper. Rack equipment uses a common width, text remains readable, and overflow continues onto additional pages. Existing manual positions and sizing are preserved.
- Fix the blank drawing caused by large imported stacks. Reduce space between members first; split oversized native stacks into labeled member continuations with their original device identity, physical ports and cross-page connections.
- Use the selected physical dimensions in the SVG, mixed-size PDF print layout and native Visio pages. Standard Visio paper kinds and orientation are included. Custom printer forms still depend on the selected printer.
- Replace the native update strip with a compact, conditional notice and a polished Help panel. Review installed/available versions, release notes, download progress, verification and installation readiness. Downloading and installation remain separate actions.
- Preserve automatic update timing, verified downloads, save-before-restart confirmation, readiness checks and rollback protection.

Existing projects retain their original page dimensions until Page options is changed. Hardware labels too small to print clearly are omitted from tiny faceplates; full port details remain in the tables. An oversized indivisible imported image may require larger paper or an explicit size edit.

Validation includes 176 Node tests, seven Python tests, independent Visio package checks, actual browser editing/save/reopen and mixed-size PDF measurements. Windows updater lifecycle, UI, export and print checks run on the final release commit. Direct rendering in Microsoft Visio is not verified in this environment.
