# NetworkDiagramStudio 0.1.0-preview.34

## Switchport report paper sizes

- Select **Paper size** and **Paper orientation** in Switchport Reports: US Letter, Legal, Tabloid/Ledger, A5, A4, A3 or A2, portrait or landscape.
- Report paper is saved with the project, independently from the network drawing's paper settings. Existing projects keep A4 landscape by default.
- Browser reports reflow and paginate to the chosen paper, with correct vector PDF page dimensions and 300 DPI PNG dimensions. Windows native exports fit their original report geometry proportionally on the chosen paper without cropping or distorting sockets.
- Exports identify non-default paper in their filenames and validation metadata. Existing A4 default filenames remain unchanged.
- Very small paper sizes can reduce printed text size in Windows native report exports; choose larger sheets for dense racks and port inventories.

## Port charts and port identification

- Keep port numbers outside socket shapes, with top-bank numbers above and bottom-bank numbers below, centered on each corresponding RJ45 or optical interface.
- Use consistent VLAN native fills, tagged dots, voice diamonds and LAG outlines without overlaying the port identifiers.
- Improve compact port-map and inventory report layouts while retaining complete port records, stack identities and physical connector proportions.
- Reduce unnecessary print space and preserve readable port/key labels and separate device scopes.

## Cleaner diagrams and editing

- Organize network devices in measured compact arrangements, preserving saved device order and avoiding arbitrary device overlaps.
- Improve cable departure clearance, parallel spacing, port names, off-page references and routing through supported modular devices.
- Retain editable connectors, Visio exports, drawing history and per-page arrangement controls.

## Verification and limitations

- The full browser/Node regression suite, Windows portable build, native paper/media-box checks, and desktop update/rollback smoke tests are required on the merged release commit.
- Report data remains configuration-derived unless the source is clearly marked as supplementary operational evidence. Synthetic test data only is included in the source and release.
- Opening a generated file in a local desktop Microsoft Visio installation is not part of the automated test gate.

Save your project before installing a new preview. The application updater still requires normal installation approval and a controlled restart.
