# NetworkDiagramStudio 0.1.0-preview.36

## Clearer controls and connection editing

- Clear editable text, search, number and multiline fields with an X button. Keyboard focus stays in the field.
- Dropdowns follow the app colors and borders. Hardware and platform suggestions show model names and complete descriptions in a matching popup, with keyboard navigation and support for custom values.
- Double-click an object to enter Edit drawing and open its editor. Text keeps direct inline editing. Connection-key lines highlight under the pointer like cables.
- The Line width preview changes immediately at its actual thickness at 100%. Legend-key width controls update the matching cables and the visible sample.
- Edit cable type, speed, color, opacity, width and captions together. Titles and descriptions expand inside the same dialog, with Save and Cancel. The old duplicate link-style navigation is removed.
- General object properties no longer show Left and Top coordinates. Move items with the mouse or arrow keys; size controls remain where relevant.
- Crossing hops reveal the background and artwork beneath their clearance instead of painting white borders.
- Shared line-width changes retain manual geometry and legend placement through Undo and project reopening. Individual connection width overrides remain available.

The portable Windows filename remains NetworkDiagramStudio.exe. Use the existing application update controls to download, verify and install the update. Save open projects before installing and restarting.
