# NetworkDiagramStudio preview.69

## Imports

- **One cable per port from Auvik exports.** Auvik reports some neighbors that are not the cable itself, and the drawing used to show them as extra cables on the same port:
  - a switch's VLAN interface (such as DEFAULT_VLAN or VLAN1) is no longer drawn as a cable;
  - when two switches see each other only through those VLAN interfaces, their two ports are joined as one cable, marked inferred in the import notes;
  - a firewall interface reported down (such as an unused dmz) is not drawn next to the port that is up;
  - a device behind another switch is drawn on that switch's port, not also on the uplink.
  Every observation is still listed under Imported data, and the import notes say which one the drawing uses and why.
- **Printer and described ports.** Printer interface names with commas (JetDirect cards) and port names followed by a description in brackets no longer create a second copy of the same cable.
- **Unidentified devices stay apart.** Two devices Auvik lists as "Unidentified Device" (or "Unknown Name") are now kept separate, named with their address, each with its own connection.

## Drawing set

- **Other devices share pages.** On VLANs and Routing and Port Inventory - Interfaces, servers, printers and other devices share pages instead of one page each. Switches, routers, firewalls and stacks keep their own pages. Devices on these pages… adds a "With other devices" choice, and "Restore default pages" returns to the default.
- Interface inventory pages of records several devices share are titled "Shared".

Save your project before updating. Opening a saved project applies the cable rules and the printer name repair without importing again. To also separate unidentified devices, import that site's Auvik files again.
