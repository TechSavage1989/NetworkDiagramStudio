- Keep rack faceplates at one shared scale across each port-map or wireless drawing family. A tall chassis or multi-member stack no longer shrinks independently to fit a fixed-height space.
- Measure the complete hardware before grouping pages. Try bounded reductions of the shared port-map scale, choose the arrangement with fewer sheets, and retain the larger scale when page counts tie. Paper size still controls the available space.
- Continue oversized native stacks by labeled member ranges, keeping their physical ports and assignment details with the corresponding hardware. Long tables and keys continue as needed without dropping records.
- Preserve the same scaling rules in compact grouped tables, expanded tables, individual-interface rows and optional repeated faceplates.
- Draw wireless connections against the correct full-width stack member, including interfaces known from neighbor links. Keep source device identities, port attachments, model/MAC captions and saved drawing edits.
- Scale compact endpoint symbols with the shared core stack width when paper size changes. Retain explicit manual sizing and positions.
- Refresh the port-map and wireless screenshots and usage details.

Existing projects need no conversion. Open the project to regenerate its pages. Imported single-image hardware remains indivisible, and explicit saved geometry remains authoritative. Larger paper may be needed for unusually tall artwork. Generated text keeps its readable font limits; physical printer support still determines custom paper availability.
