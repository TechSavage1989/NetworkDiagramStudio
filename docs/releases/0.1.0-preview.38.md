# NetworkDiagramStudio 0.1.0-preview.38

## Visible paper settings restored

- Page Options again controls the visible sheet, including Letter, Legal, A4, A3 and other paper proportions, portrait/landscape and Dynamic / Fit all.
- Apply these proportions to all pages, a selected page group or one individual drawing page. Group and page settings override the drawing default; Inherit removes an override.
- Changing proportions adjusts the visible white page boundary and fits the complete existing drawing inside it. Equipment, cable paths, port mappings, legends, manual edits and logical page count are unchanged.
- Printing can follow the visible page or use a different physical paper size.

## Port maps and wireless layout

- Switch stacks containing up to eight members fit on one logical Port Map page with a single VLAN/LAG key and complete member port details.
- Wireless connections now allocate switch-side departure levels in physical port order, so levels do not jump merely because a cable travels left rather than right. The collision and port-clearance checks are retained.

The portable Windows filename remains NetworkDiagramStudio.exe. Save open projects before updating. Use the existing application's update controls, or obtain the Windows executable from this release.
