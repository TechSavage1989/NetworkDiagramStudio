# NetworkDiagramStudio 0.1.0-preview.7

- Double-click an editable diagram element to open its editor. Text opens directly on the diagram, including text inside supported native device artwork. Enter saves, Escape cancels, and clicking elsewhere commits a valid edit before the next action. Save/export cannot miss text that is still being edited. A single device click still finds its stencil; it is delayed briefly so a double-click can open properties.
- Drag a selection rectangle over diagram items in Edit drawing. Shift adds enclosed items, Ctrl toggles them, and Alt selects native panel details. Space-drag and the middle mouse button still pan. Rectangle selection uses page coordinates at the current zoom.
- Arrow keys move the selected objects or group. The normal step is configurable; Shift uses ten times that step and Ctrl uses one tenth. Cable bend points use the same keys and retain attached endpoints.
- Snapping and automatic alignment are configurable per project. Choose grid spacing, alignment distance, and device edges/centers, other object edges, or cable points as alignment targets. Guide lines appear while snapping. Snapping starts disabled to preserve existing placement behavior. Press Alt after starting a drag to bypass it temporarily. Keyboard nudges retain their exact step.
- Ctrl+Z undoes and Ctrl+Shift+Z redoes project changes when focus is outside a text field. Undo all reverses the available session history; Redo reapplies those changes in order. History includes text, positions, styles, endpoint connections, port mappings, imports and project settings. Port mapping has scoped Undo, Redo and Undo all controls. Typing fields retain native text undo. The available history is bounded to 200 actions, and loading a project starts a new history. Save/reopen preserves edits and snapping settings, not the in-memory undo stack.
- The full visual line color picker, editable app icon, used-only color legends, cable bend tools, physical endpoint selectors and cleaner port tables from preview.6 remain included.

Local validation covers 63 Node tests; direct mouse/keyboard checks for inline editing, double-clicks, rectangle selection, modifier nudging, grid/guide snapping, project history and save/reopen; the existing cable/color/port-map regressions; and the private core geometry check. Windows production/native-test-host compilation, cross-publishing, icon/version resources, embedded editor checks and packaging passed. Hosted native Windows update/rollback and direct Visio opening remain separate validation requirements. This candidate has not been published to the GitHub update feed.
