# NetworkDiagramStudio preview.60

## Pages and settings

- **Lock and All pages in the page bar.** Next to the paper size and orientation there is now a **Locked/Unlocked** button and an **All pages** tick box.
- **One rule for settings everywhere.** A change made for **All pages** sets every page, including pages that had their own setting. A change made later on one page overrides it for that page, until you make another all-pages change. This applies to:
  - the page bar;
  - Paper & print;
  - Layout & content drawing defaults;
  - the name and details positions;
  - Global text styles (a style change now also applies to text you edited individually).
- **Paper layout is simpler.** Choose **Optimize for paper** or **Keep the existing layout**. The wireless-only choices are in their own **Wireless pages** section.
- **Global text styles show what you are styling.** Open a category and its text lights up in the preview, with a count of how many items there are on that page.
- **The desktop app remembers its window** size, position and maximized state.

## Network pages

- **Show wireless access points on the network pages**: Layout & content → *Show wireless access points on network pages* (also in Device order). Short access point names stay on one line.

## Port maps, Port Inventory, VLANs and Routing

- The safety note on port maps no longer overlaps the symbol key.
- **Port Inventory** text is smaller, so more fits on each page. Each page is named after the devices on it, for example *Port Inventory - LAB-SW01-MDF, LAB-2FL-IDF-STACK*.
- **VLANs and Routing** keeps each device whole on one page. A device that doesn't fit in the space left moves to the next page, and a smaller device that does fit fills that space. Only a device too large for a whole page continues onto another page.
