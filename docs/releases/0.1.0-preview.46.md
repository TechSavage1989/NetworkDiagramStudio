# NetworkDiagramStudio preview.46

## Cleaner information panels

- Selected sections with no content now disappear, including their headings. No Port modules / GBICs heading appears when no modules are recorded.
- Existing saved projects adopt this behavior. Custom text, notes and deliberately edited body rows are preserved; a custom heading alone does not create an empty section.
- If wanted for troubleshooting, explicitly choose **Pages & layout → Sections without data → Show an explanation**.
- Empty panels no longer leave a separator, and blank route records no longer create misleading rows.

Save your project before updating. The same scene content is used for the editor, print/PDF, SVG, interactive HTML and native Visio exports.

## Readable paper and smaller information rails

- **Pages & layout → Minimum paper text (pt)** defaults to 8pt for general editable diagram captions, device details and link/port labels. Set it globally or for one page; **Text scale (%)** scales the target too. Set the minimum to 0 to disable it.
- Automatic fitting enlarges the model uniformly instead of growing letters over nearby cables. If readable content cannot fit on the selected sheet, the app warns about overflow. Choose larger paper, fewer details or continued sheets rather than shrinking everything unnoticed.
- Explicit individual font sizes, saved page frames, manufacturer artwork and adaptive/native report typography remain authoritative. Small-text notices identify preserved layouts that need review; this is not a promise that every printed mark is at least 8pt. Use Page options to deliberately recalculate an older saved fit.
- Information panels now use compact measured widths. **Panel width (% of paper; 0 = automatic)** reserves 10–60% of usable sheet width when explicitly set and rewraps complete content without shrinking it. Existing source-unit width remains useful on Dynamic canvases.

## In-app guide

The always-visible **User guide** works offline, before or after opening a project. Search task-oriented instructions for paper sizing, screen calibration, panels, transforms, undo and export, with shortcuts to the relevant settings. Desktop update **Help** remains separate.

## Optical faceplate proportions

Generic SFP/QSFP socket and optical-module fronts now use sourced schematic aspect ratios instead of overly slim generic rectangles. Socket centers, widths, copper geometry and imported manufacturer artwork are preserved. The diagrams remain schematics, not engineering-scale chassis drawings; references and limits are documented in `docs/OPTICAL_GEOMETRY.md`.

## Wireless AP size and side-space layout

- **Wireless APs and details (%)** scales automatic AP bodies and their associated labels together, globally or per page. Individual authored sizing/text remains authoritative.
- **Wireless AP placement → Use side space** deliberately tries measured side columns. **Preserve rows (default)** keeps existing row layouts. Unsafe or worse-crossing side candidates fall back to rows; explicit positions and frozen layouts are preserved.
- The synthetic 28-AP fixture at 150% AP scale improves from 16 crossings to 8 without collisions or merged strokes. This does not promise every dense topology fits on Letter at readable size.
- New physical-sheet port numbers request readable size during planning rather than scaling the entire switch afterward. Stock Letter wireless sheets fit with measured 8.26pt text. Saved frames retain that plan across reopening.
- Inventory title bands remain behind their white headings. Near-fit pages reclaim only needed outside whitespace, with a visible warning for genuine overflow. Small layout margins are not a guarantee of a printer's physical printable area.
