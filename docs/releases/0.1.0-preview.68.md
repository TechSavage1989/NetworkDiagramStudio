# NetworkDiagramStudio preview.68

## Drawing set

- **One VLANs and Routing page per switch.** Each switch, firewall or router with VLANs or routes now starts its own VLANs and Routing page, named after it. The members of a device stack share one page. Records that several devices have in common are still listed once on a Shared page.
- **One Port Inventory page per switch.** Port Inventory and Port Inventory - Interfaces work the same way: each switch or stack starts its own pages.
- **Put devices together when you want.** Right-click a VLANs and Routing or Port Inventory page in the page list and choose **Devices on these pages…** (or click Move to page… on one of these pages in Edit drawing). For each device choose Own page or With another device, then Apply. Undo reverses it, and One page per switch or stack returns to the default.

## Fixes

- Editing a VLANs and Routing page heading no longer stops records shared by several devices from being listed together.
