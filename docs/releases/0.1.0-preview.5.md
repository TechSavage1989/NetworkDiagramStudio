# NetworkDiagramStudio 0.1.0-preview.5

- Simpler core links. Routing considers bend count before length, removes unnecessary detours and fits nearby device titles around the cable path. Facing ports can use straight or two-bend links; exterior routes retain consistent spacing and crossing jumps.
- Editable link-color legends on core and wireless pages. Endpoint port names and media/speed labels remain legible and clear of text and cables.
- Direct dragging in Edit drawing, Shift-click multiple selection, edge/center alignment, equal spacing, Undo and Redo. Hold Space to pan. Double-click or Edit selected changes text, names, size and style; Alt-drag moves individual native panel details. Cable ends stay glued to their ports.
- Port mapping supports dragging markers, row/column alignment, equal horizontal/vertical spacing and its own Undo control.
- Search directly in the Visio master picker. Selected masters remain selected when the search changes.
- Continued sheets retain independent device positions. Native vector text preserves weight/alignment in SVG and Visio, and shape names persist in Visio.

This candidate includes the unpublished preview.3/preview.4 stencil, hardware, evidence, zoom/pan and manual updater changes. It preserves schema-1 projects and hardware packs. Raster stencil artwork remains a movable/resizable image; supported native artwork retains independently editable paths and text.

Local automated and browser checks cover geometry, dragging, selection, alignment, spacing, search, port mapping, save/reopen and native export structure. Hosted Windows export/print, timers, installation and rollback must pass before public release. Successful conversion through installed desktop Visio and direct Visio opening remain untested here.
