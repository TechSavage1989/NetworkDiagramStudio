# NetworkDiagramStudio 0.1.0-preview.44

## More usable page space

- Fit measured diagram content rather than large empty source margins. Site, page-title and NETWORK DOCUMENTATION headings keep readable paper sizes.
- Deliberate scale/move edits retain the accepted page frame, so automatic fitting does not undo their visible size change. Saving Page options recalculates the fit.

- Auto-fit uses slimmer gutters and enlarges stack/chassis port maps to the available paper width instead of stopping at the reference socket size. Complete port labels and VLAN/LAG keys remain visible; socket proportions remain unchanged.
- Preserve layout and locked-sheet fitting frames retain their established sizing. Print paper remains independent, and standalone native report printing keeps its quarter-inch margin.

## Coherent paper layouts

- Selecting paper proportions keeps the complete wireless arrangement together and fits it proportionally by default. An explicit readable-continuation option remains available when printed label size matters more than page count.
- Readable continuation measures AP captions and route lanes before splitting, fitting more complete content per sheet without reducing caption fonts.

## Selection, transforms and page locks

- Ctrl+A / Command+A selects diagram content without the information panel or page frame. Text fields keep normal Select All, and diagram dragging does not accidentally select editor UI text.
- Scale, rotate and move complete selections with Undo/redo. Off-page content remains visible while editing.
- Page locks fix sheet dimensions, not item size or placement. Scaling and moves may extend beyond locked sheets; a visible warning identifies possible print/export clipping. Choosing a paper preset no longer automatically enables its lock.
- A bounded right-hand AP return-lane improvement reduces avoidable crossings while preserving left-side routing, paired switch departures, AP positions and physical sockets. Some crossings can remain in dense bundles.

Fitting a large layout on small paper can make labels small. Choose larger paper or readable continuation when necessary. Save open projects before updating. Previous releases remain available. Interactive rendering in Microsoft Visio itself has not been verified.
