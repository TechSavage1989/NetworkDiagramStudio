# NetworkDiagramStudio preview.57

## Real font sizes

- **Text styles** now take an actual font size in points for each kind of text (device names, port labels, connection labels and so on). Leave a size blank to keep the built-in sizes.
- Under each size you can see what it prints at on the page you have open. A page fitted to Letter or other paper prints proportionally smaller.
- The **Size** box in Edit drawing and the object **Properties** also use points.

## One "Optimize for paper" choice

- **Paper & print → Paper layout** replaces the separate content-fit and wireless choices.
- **Optimize for paper** (the default) makes every page, not just the APs, as large and readable as the sheet allows: network pages, port maps, tables and wireless sheets.
- You can still continue wireless sheets to keep AP text at 8 pt, keep wireless arrangements as you drew them, or keep the existing layout.

## Names and details stay with their device

- On the **Core Network** page, each device's name sits directly above it and its details directly below it, on the left.
- If a cable is in the way, the text slides along the same edge rather than jumping away.
- Choose a different corner for names and for details in **Layout & content → Device name position / Device details position**.

## Text no longer shrinks when you move things

- Moving a name, a detail line or a device kept the text readable only until the first move. The text then dropped back to a small size. It now keeps its readable size.

## Faster editing

On a large site:
- Moving something on the network page takes about a third of the time it did.
- Moving an AP again takes less than half the time.
- Undo is faster.
- Changing a text style takes a fraction of a second instead of several seconds.

Save your project before updating.
